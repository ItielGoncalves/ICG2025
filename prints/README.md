# Pasta de prints / capturas

Salve aqui os prints de **e-mail**, **agenda** e **WhatsApp** que devem entrar
no briefing diário. A rotina lê todas as imagens desta pasta, faz OCR/visão e
inclui um resumo organizado no áudio.

- **Caminho padrão:** esta pasta (`<repo>/prints`).
- **Para mudar o caminho:** defina a variável de ambiente `BRIEFING_PRINTS_DIR`
  com o caminho desejado (por exemplo, uma pasta sincronizada do Google Drive).
- **Formatos aceitos:** `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.

Os arquivos de imagem ficam fora do controle de versão (ver `.gitignore`); só
este README é versionado.
